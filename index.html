PagedAttention slashes memory, boosts LLM serving throughput while preserving accuracy

Efficient Memory Management for Large Language Model Serving with PagedAttention

Woosuk Kwon, Zhuohan Li, Siyuan Zhuang · Semantic Scholar · 9/10 signal

Integrate PagedAttention into your inference pipeline to double batch size on the same GPU.

Serving large language models at scale is bottlenecked by GPU memory; traditional attention kernels force tiny batch sizes or costly model parallelism.

PagedAttention partitions the attention matrix into fixed-size pages that can be swapped between GPU and CPU on demand, preserving the linear‑time attention algorithm while dramatically lowering peak memory.

Practitioners can double or triple batch size on existing hardware, cut inference cost, and integrate the technique with minimal code changes, directly improving goodput for production services.
