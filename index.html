Differentiable curves turn vector graphics into trainable primitives

TorchCurves: Differentiable Parametric Curves

Alex Shtoff · cs.LG · 9/10 signal

Replace raster masks with differentiable curve primitives to boost accuracy and parameter efficiency.

TorchCurves introduces a PyTorch library that treats parametric curves as first‑class learnable objects. By exposing a differentiable mapping from control points to rasterized pixels, it enables end‑to‑end training of vector‑based representations alongside standard deep nets.

The authors demonstrate the utility on shape reconstruction, stroke‑based image synthesis, and as a drop‑in replacement for raster masks in segmentation pipelines, reporting up to 15% IoU gains with far fewer parameters.

The whole edition, one paper

The problem
Current vision models ingest rasterized images, discarding the compact, analytically tractable structure of vector graphics. This limits resolution scalability, introduces aliasing, and forces networks to learn redundant pixel‑level patterns instead of shape semantics.
How it works
TorchCurves parameterises each curve segment (Bezier, B‑spline, or custom polynomial) by a set of control points. It implements a differentiable rasteriser based on soft‑mask rendering: each pixel receives a weighted contribution from nearby curve segments using a smooth distance field, enabling gradients to flow back to the control points. The library batches curve sets, supports arbitrary order derivatives, and integrates seamlessly with autograd, allowing curves to be optimized jointly with downstream CNN or transformer heads.
What they measured
On the QuickDraw stroke dataset, a curve‑only model achieved 92.3% classification accuracy versus 84.7% for a comparable CNN with the same parameter budget. In a medical segmentation task (ISIC skin lesions), substituting raster masks with TorchCurves reduced the parameter count by 40% and improved Dice score from 0.81 to 0.86. Training time overhead was modest (~1.2×), and memory usage dropped by 30% due to the compact control‑point representation.
Where it breaks
The method assumes smooth, well‑behaved boundaries; highly textured or noisy regions still require raster support. Differentiable rasterisation introduces approximation error that can bias gradients for very thin structures. Moreover, the library currently supports only 2‑D curves, limiting direct extension to volumetric data. Finally, performance gains depend on the existence of a meaningful vector prior; domains lacking such priors may see negligible benefit.
What this unlocks
Practitioners can now embed vector‑based shape priors directly into training loops, enabling high‑resolution rendering at inference without memory blow‑up. This opens the door to scalable SVG‑style generation, lightweight segmentation models for edge devices, and hybrid pipelines where coarse curve predictions are refined by pixel‑level nets only where needed.
