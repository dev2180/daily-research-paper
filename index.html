GPU-CFR shatters speed limits, delivering 80× faster game solving today

GPU-CFR: 80x Faster Counterfactual Regret Minimization by Compiling the Game to Static Dataflow and CUDA Graph Replay

Boning Li, Longbo Huang · cs.DC · 9/10 signal

Compile CFR pipelines into reusable CUDA graphs to unlock GPU acceleration.

CFR remains a rare large‑scale workload that outperforms GPUs, limiting research and commercial bots that need rapid equilibrium computation.

The authors compile the entire game logic into a static dataflow graph and replay it with CUDA‑graph capture, eliminating per‑iteration kernel launch overhead and achieving an 80× speedup.

Practitioners can now run billion‑iteration CFR sweeps on a single GPU, cutting cloud costs and opening real‑time strategy applications.
